# 拼豆工具

一套拼豆（Perler / Fuse Beads）图案制作工具：导入图片 → 压缩成像素图 → 映射豆色 → 简化颜色 → 手动编辑 → 保存 / 撤销 → 导出图片。基于 **Python（Flask）+ HTML/JavaScript**，数据保存在本地，刷新后自动还原。

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:5000 即可（默认 5000 端口，可用环境变量 `PORT` 覆盖；需 Python 3.9+）。本地直开与打包版会在后端就绪时自动打开浏览器，`NO_BROWSER=1` 可关闭；Docker 容器内不自动打开。

## 部署方式

- **Docker / NAS**：在 `docker-compose.yml` 设置 `APP_TOKEN`（必填）、`APP_SECRET`（建议随机）、`PUID/PGID`（按挂载目录属主），`docker compose up -d --build` 后访问 `http://NAS地址:5000` 并输入 Token。数据存于 `./data`，升级不丢；首次启动自动补齐内置色板；容器内以 Waitress 降权运行，公网请配 HTTPS 反向代理。
- **Windows EXE**：双击 `build_exe.bat` 打包，产物 `dist\fuse-beads-tool.exe` 单文件双击即用，启动后常驻系统托盘（双击图标打开网页、右键退出、单实例不重复启动）；数据存于 exe 同级 `data` 目录，需 Token 时提前设置 `APP_TOKEN`。更换图标：替换 `assets\app-icon.png` 后重新打包（自动生成多尺寸 ICO）。

> Token 验证：设置 `APP_TOKEN` 后所有 API 需登录（状态存于会话 Cookie）；未设置时本地直接访问。

## 功能说明

### 1. 导入与压缩

- 支持常见图片格式并处理 EXIF 方向；PNG 透明区显示为空位（浅灰 ×），半透明像素按白底合成。
- 「分块平均 + 感知色域量化」压缩，可勾选锐化；目标像素量默认 5000（上限 80000），提供 500 / 2500 / 5000 / 10000 预设下拉（带提示），超出自动等比缩放。目标像素量按“期望的非空豆量”计算：含透明区域的图片会先按透明比例放大中间压缩目标，使最终非空豆量接近输入值。
- 画布按像素格显示（默认每格 28px；边缘粗黑、格内细灰、每 5 格粗灰虚线、每 10 格粗灰实线，四周 1 格浅蓝底行列号条，外圈无线），右下角显示总量与空位数；工具栏可切换显示色号 / 透明色（仅影响工作区，导出时单独设置）。

### 2. 豆色配置

- 内置 MARD 221 色（默认）与 48 色示例；支持新建 / 重命名 / 删除、直接编辑颜色表、CSV 导入导出（UTF-8 BOM，表头 `编号,色号,名称,颜色`，兼容英文表头）。
- 配置修改不直接生效，单击「重新压缩」后按新配置重新生成图案。

### 3. 颜色简化

- 每个像素取距离最近的豆色（默认 Lab 感知距离，可切换 RGB）；平局按「已使用数量最多 → 左-上-右-下」确定；修改距离后同样需「重新压缩」生效。
- 双副本模型：基副本为滑块调整前的数据，工作副本为调整后的结果；「颜色数量」滑块按像素数加权合并相近色，并清空事务与撤销记录（有警告）。

### 4. 编辑模式

- **选择模式**（默认）：左键单击 / 拖拽选矩形（连通区域合并为整块外轮廓），Shift 追加多选，ESC 清除；「同色选区」只选四方向相连的同色像素，「选中高亮」把当前高亮色号的全部像素转为选区；右键任意位置拖拽平移。
- **画笔 / 橡皮**：点选颜色进入画笔连续涂色（未选色时自动取调色板最暗色；有选区时点击颜色 = 填充选区，保持选择、记一步撤销）；橡皮擦除为空位；尺寸 1-10 时按边长 2n-1 的矩形涂色 / 擦除。画笔 / 取色 / 橡皮按 ESC 返回选择模式。
- **取色**：点击像素取色；有选区时立即填充选区并回选择模式，无选区时切到画笔模式。
- **魔棒模式**（M 键 / 「魔棒」按钮）：点击起点，按当前「容差」选中四向连通的相似色；Shift 点击追加选区，容差 0 等价于只选同色。适合去背景、批量换色、清理杂色；选中后可 Delete 清空或点击颜色填充。
- **颜色清单**：右侧按数量列出已用色号，点击高亮对应像素（半透明覆盖层 + 亮度自适应描边）。
- **D 键九宫格**（选择模式）：单选一格时作用于选中格，否则作用于悬停格；优先取周围 8 格颜色，不足按相近度补齐；悬停实时预览，点击或按 1-9 确认改色。
- **裁剪模式**（R 键 / 「裁剪」按钮）：红色边框 + 40% 黑色蒙版，裁剪矩形内保持清晰；支持选中 / 拖拽边（行列号条内也可操作）、点击平行格线移动边、自动裁剪到非空格包围盒；「应用」生成裁剪前事务快照并支持整体撤销 / 重做；ESC 或切换工具取消。

### 5. 工作区视图

- **侧边栏折叠 / 展开**：左右三个面板都可收起为窄条（左侧收起时画布保持原位）。
- **对比原图**：勾选后左侧显示原图（可独立缩放拖拽，不可编辑），右侧为拼豆图。
- **同步拖拽**：勾选后两侧坐标与缩放一致，任一侧拖拽 / 缩放另一侧跟随；未勾选对比时勾选同步会自动开启对比。
- **日间 / 夜间模式**：标题行右侧按钮切换，首次跟随系统深浅色并记忆偏好；画布四角透明，工作区背景随主题变化。

### 6. 事务与撤销

- 工作状态自动保存，刷新后还原；Ctrl+S 保存独立快照（非树状结构），右侧事务历史可切换 / 删除。
- 自动保存会记录：设置、视口（缩放 / 平移）、当前工具与画笔颜色、选区、未保存修改标记、画布与基副本、单步撤销 / 重做栈、事务历史、后端原图引用；下次打开时恢复这些运行态。
- 导入的原图会按内容哈希保存到 `data/originals/`，「重新压缩」可直接从后端原图提取；浏览器 IndexedDB 仍作为「对比原图」的缓存与降级来源。
- 项目与每个事务快照都会保存色板哈希；打开 / 刷新 / 切换事务时按哈希检查配置，配置缺失或与快照不一致时会自动创建「原名 (恢复 哈希前8位)」配置并更新引用，原配置不会被覆盖。
- 撤销 / 重做（Ctrl+Z / Ctrl+Y，最多 20 步，增量记录）；D 键改色、画笔 / 橡皮整段、选区填充各记一步。
- 重新压缩或调整滑块会清空事务与撤销记录（有警告）；「清空所有状态」清空画布与全部历史。

### 7. 导出图片

- 导出 JPG / PNG：实时预览 + 每格大小、网格线、外部白边、行列号、色号、图例、透明色、格式设置；导出期间显示进度条并锁定对话框，完成后自动关闭。
- 导出内容与画布一致（含合并后的颜色效果）；行列号按需勾选，图例格式为「色号 × 数量」。
- 导出 PDF：支持 A4 单页、A4 多页、A3 或 A4 三种模式，四周留白 5mm。单页模式自动缩放并选择横/纵向；多页模式先输出「总」览页，宽 >50 或高 >60 时按 35/30、40/35 等规则拆分分页，分页页行列号延续原图坐标、只显示本页图例，左上角标注总 / 1 / 2 / 3...；导出对话框右下角可切换预览页面，纸张以 A4/A3 灰底呈现。

### 8. 项目文件（.ssfbp）

- 「打开项目」在导入图片左侧，「保存项目」在导出图片右侧；快捷键 Ctrl+Shift+S 保存项目，Ctrl+S 仍是保存事务。
- `.ssfbp` 是单一二进制文件：内部为段表结构，包含格式版本、状态、原图、视口（缩放 / 平移）与校验信息；不保存撤销栈、当前工具、选区等运行态。
- 本地 Windows 由后端直接保存：首次保存弹出系统对话框，之后覆盖当前项目文件；Docker / NAS 等非 Windows 环境自动改为浏览器下载。
- 打开项目前如果任何会写入项目文件的文档数据（设置、画布、事务、色板等）发生过变化，会先提示确认；纯像素编辑的 `dirty` 不参与该提示。
- 事务历史随项目文件保存，打开后整体替换当前事务历史；基线红点也会保留；打开时会还原保存时的工作区缩放与平移。

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 色板配置 | `data/configs/*.csv` |
| 当前状态与事务历史 | `data/state.json`（自动生成） |
| 导入原图 | `data/originals/`（按内容哈希存储，自动生成） |

> 「对比原图」的原图缓存在浏览器 IndexedDB，刷新后仍可用；导入新图时更新。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Ctrl+S / Cmd+S | 保存事务状态 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（最多 20 步） |
| D / 1-9 | 相近色九宫格 / 选择（单选格优先，否则悬停格） |
| Q / W / E | 切换画笔 / 取色 / 橡皮 |
| R | 裁剪工具（ESC 取消返回选择模式） |
| M | 魔棒工具（按容差选择四向连通的相似色；ESC 返回选择模式） |
| Delete | 清除选中格为空位（记一步撤销） |
| Esc | 关闭九宫格、清除选择、返回选择模式 |
| 鼠标滚轮 / 右键拖拽 | 缩放 / 平移画布 |

> 焦点不在输入框内时已拦截 Ctrl+S，不会触发浏览器「另存为」对话框。
