# 拼豆工具

一套拼豆（Perler / Fuse Beads）图案制作工具：导入图片 → 压缩成像素图 → 映射豆色 → 简化颜色 → 手动编辑 → 保存 / 撤销 → 导出图片。基于 **Python（Flask）+ HTML/JavaScript**，数据保存在本地，刷新后自动还原。

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:5000 即可（固定 5000 端口，可用环境变量 `PORT` 覆盖；需 Python 3.9+）。本地直开与打包版都会在后端就绪时自动打开浏览器，设置 `NO_BROWSER=1` 可关闭；Docker 容器内不自动打开。

## 部署方式

- **Docker / NAS**：在 `docker-compose.yml` 设置 `APP_TOKEN`（必填）、`APP_SECRET`（建议随机）、`PUID/PGID`（按挂载目录属主），执行 `docker compose up -d --build`，访问 `http://NAS地址:5000` 并输入 Token。数据存于 `./data`，升级不丢；首次启动自动补齐内置色板；容器内降权以 Waitress 运行，公网请配 HTTPS 反向代理。
- **Windows EXE**：双击 `build_exe.bat` 打包，产物 `dist\fuse-beads-tool.exe` 单文件双击即用。启动后为系统托盘后台常驻（双击图标打开网页、右键退出、单实例不重复启动）；数据存于 exe 同级的 `data` 目录，需 Token 时提前设置环境变量 `APP_TOKEN`。更换图标：替换 `assets\app-icon.png` 后重新打包（自动生成多尺寸 ICO）。

> Token 验证：设置 `APP_TOKEN` 后所有 API 需登录（状态存于会话 Cookie）；未设置时本地直接访问。

## 功能说明

### 1. 导入与压缩

- 支持常见图片格式并处理 EXIF 方向；PNG 透明区显示为空位（浅灰 ×），半透明像素按白底合成。
- 「分块平均 + 感知色域量化」压缩，可勾选锐化；目标像素量默认 5000（上限 80000），提供 500 / 2500 / 5000 / 10000 常用预设下拉（带悬浮提示），超出自动等比缩放。
- 画布按像素格显示（默认每格 28px；边缘粗黑线、格内细灰线、每 5 格粗灰虚线、每 10 格粗灰实线，四周 1 格浅蓝底行列号条且外圈无线），右下角显示总量与空位数。
- 画布工具栏可开启显示色号 / 切换透明色（仅影响工作区；导出时单独设置）。

### 2. 豆色配置

- 内置 MARD 221 色（默认）与 48 色示例；支持新建 / 重命名 / 删除配置、直接编辑颜色表、CSV 导入导出（UTF-8 BOM，表头 `编号,色号,名称,颜色`，兼容英文表头）。
- 配置修改不直接生效，单击「重新压缩」后按新配置重新生成图案。

### 3. 颜色简化

- 每个像素取距离最近的豆色（默认 Lab 感知距离，可切换 RGB）；平局按「已使用数量最多 → 左-上-右-下」确定。
- 颜色距离修改后同样需「重新压缩」生效。
- 双副本模型：基副本为滑块调整前的数据，工作副本为调整后的结果；「颜色数量」滑块按像素数加权合并相近色，并清空事务与撤销记录（有警告）。

### 4. 编辑模式

- **选择模式**（默认）：左键单击选单格、左键拖拽选矩形（虚线显示，连通区域合并为整块外轮廓），Shift 追加多选，ESC 清除；勾选「同色选区」后单击只选四方向相连的同色像素；「选中高亮」把当前高亮色号的全部像素转为选区并取消高亮。右键在工作区内任意位置拖拽平移。
- **画笔 / 橡皮**：点选颜色进入画笔模式连续涂色（未选色时按画笔自动取调色板最暗色）；橡皮擦除为空位；「尺寸」拖动条（1-10）把画笔 / 橡皮改为边长 2×数值−1 的矩形。
- **取色**：点击像素取色；有选区时取色后回选择模式并立即填充选区，无选区时自动切到画笔模式。
- **颜色清单**：右侧按数量列出已用色号，点击可高亮对应像素（半透明覆盖层 + 亮度自适应描边）。
- **D 键九宫格**（仅选择模式）：单选一格时作用于选中格，否则作用于悬停格；优先取周围 8 格颜色，不足 9 个按相近度补齐；悬停候选实时预览，点击或按 1-9 确认改色。
- 选择模式有选区时点击「全部颜色」里的颜色 = 填充选区（保持选择、记一步撤销）；无选区时点击颜色进入画笔模式。画笔 / 取色 / 橡皮按 ESC 返回选择模式。
- **裁剪模式**（R 键 / 编辑工具区「裁剪」按钮）：红色纯边框 + 40% 黑色蒙版覆盖整个工作区，裁剪矩形内保持清晰；支持选中 / 拖拽边（行列号条内也可操作）、点击平行格线移动边；「自动裁剪」收缩到非空格包围盒；「应用」生成裁剪前事务快照并支持整体撤销 / 重做；ESC 或切换工具取消。

### 5. 工作区视图

- **侧边栏折叠 / 展开**：左侧「色板配置 & 编辑工具」与右侧「颜色清单」「事务历史」都可收起为窄条（左侧收起时画布保持原位）。
- **对比原图**：勾选后左侧显示原图（可独立缩放拖拽，不可编辑），右侧为拼豆图。
- **同步拖拽**：勾选后两侧坐标与缩放一致，任一侧拖拽 / 缩放另一侧跟随；未勾选对比时勾选同步会自动开启对比。
- **日间 / 夜间模式**：标题行右侧按钮切换，首次跟随系统深浅色并记忆偏好；画布四角透明，工作区背景随主题变化。

### 6. 事务与撤销

- 工作状态自动保存，刷新后还原；Ctrl+S 保存独立快照（非树状结构），右侧事务历史可切换 / 删除。
- 撤销 / 重做（Ctrl+Z / Ctrl+Y，最多 20 步，增量记录）；D 键改色、画笔 / 橡皮整段、选区填充各记一步。
- 重新压缩或调整滑块会清空事务与撤销记录（有警告）；「清空所有状态」清空画布与全部历史。

### 7. 导出图片

- 导出 JPG / PNG，实时预览 + 每格大小、网格线、外部白边、格内色号、行列号、图例、透明色、格式设置；导出期间显示进度条并锁定导出对话框，完成后自动关闭。
- 导出内容与画布一致（含合并后的颜色效果）；行列号按需勾选，图例格式为「色号 × 数量」。

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 色板配置 | `data/configs/*.csv` |
| 当前状态与事务历史 | `data/state.json`（自动生成） |

> 「对比原图」的原图缓存在浏览器 IndexedDB，刷新后仍可用；导入新图时更新。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Ctrl+S / Cmd+S | 保存事务状态 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（最多 20 步） |
| D / 1-9 | 相近色九宫格 / 选择（单选格优先，否则悬停格） |
| Q / W / E | 切换画笔 / 取色 / 橡皮 |
| R | 裁剪工具（ESC 取消返回选择模式） |
| Delete | 清除选中格为空位（记一步撤销） |
| Esc | 关闭九宫格、清除选择、返回选择模式 |
| 鼠标滚轮 / 右键拖拽 | 缩放 / 平移画布 |

> 焦点不在输入框内时已拦截 Ctrl+S，不会触发浏览器「另存为」对话框。
