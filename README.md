# 拼豆工具

一套拼豆（Perler / Fuse Beads）图案制作工具：导入图片 → 压缩成像素图 → 映射豆色 → 简化颜色 → 手动编辑 → 保存 / 撤销 → 导出图片。基于 **Python（Flask）+ HTML/JavaScript**，数据保存在本地，刷新后自动还原。

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:5000 即可（固定 5000 端口，可用环境变量 `PORT` 覆盖；需 Python 3.9+）。本地直开与打包版都会在后端就绪时自动打开浏览器，设置 `NO_BROWSER=1` 可关闭；Docker 容器内不会自动打开。

## 部署方式

- **Docker / NAS**：项目放到 NAS 后编辑 `docker-compose.yml`，设置 `APP_TOKEN`（必填）、`APP_SECRET`（建议随机）、`PUID/PGID`（按挂载目录属主），执行 `docker compose up -d --build`，访问 `http://NAS地址:5000` 并输入 Token。数据保存在 `./data`，升级不丢；首次启动自动补齐内置色板；容器内按 `PUID/PGID` 降权并以 Waitress 运行，不自动打开浏览器，公网请搭配 HTTPS 反向代理。
- **Windows EXE**：双击 `build_exe.bat` 打包（内部调用 pyinstaller），产物 `dist\fuse-beads-tool.exe` 单文件双击即用。启动后作为后台进程常驻，**右下角系统托盘出现图标**（不在任务栏显示）：双击图标打开网页，右键菜单可退出进程；再次双击 exe 不会重复启动，而是直接打开网页（单实例）。首次启动仍会自动打开浏览器，`NO_BROWSER=1` 可关闭。数据保存在 **exe 同级的 `data` 目录**，需要 Token 认证时提前设置环境变量 `APP_TOKEN`。

  > 更换图标：替换 `assets\app-icon.png`（应用图标源文件，托盘与 EXE 图标共用），重新运行 `build_exe.bat` 即可；脚本会自动由 PNG 生成多尺寸 ICO。

> Token 验证：设置 `APP_TOKEN` 后所有 API 均需登录（状态存于会话 Cookie）；未设置时本地直接访问。

## 功能说明

### 1. 导入与压缩

- 支持常见图片格式，自动处理 EXIF 方向；PNG 透明区域显示为空位（浅灰 ×），半透明像素先按白底合成再取色。
- 采用「分块平均 + 感知色域量化」压缩，可勾选**锐化**；**目标像素量**默认 40000，超出自动等比缩放。
- 画布按像素格显示（细线网格、每 5 格加粗、四周 5 格灰色 × 边距），右下角显示总量与空位数；工作区不显示外部白边与图例。
- 画布工具栏可开启**显示色号**或切换**透明色**，仅影响工作区显示；导出时的色号与透明色在导出对话框中单独设置。

### 2. 豆色配置

- 内置 **MARD 221 色**（默认）与 **48 色示例**；支持新建 / 重命名 / 删除配置、直接编辑颜色表、CSV 导入导出（UTF-8 BOM，兼容 `id/code/name/hex` 等英文表头，表头为 `编号,色号,名称,颜色`）。
- 配置修改（编辑颜色、增删、切换）**不直接生效**，单击「重新压缩」后才按新配置重新生成图案。

### 3. 颜色简化

- 为每个像素找**距离最近**的豆色（默认 Lab 感知距离，可切换 RGB）；唯一最近色直接确定，多色平局按「已使用数量最多 → 左-上-右-下」确定。
- **颜色距离（Lab / RGB）修改后不立即生效**，单击「重新压缩」后才按新算法重新生成图案。
- 采用**双副本**模型：**基副本**为滑块调整前的数据，**工作副本**为调整后的结果，编辑直接改工作副本；拖动「颜色数量」滑块按像素数加权合并相近色，并清空全部事务与撤销记录（有警告）。

### 4. 编辑模式

- **拖拽模式**（默认）：拖动平移、滚轮缩放、单击像素高亮。
- **画笔 / 橡皮**：点选颜色进入画笔模式连续涂色；橡皮拖拽擦除为灰色 × 空位。
- **取色**：点击像素取用颜色并自动切到画笔模式。
- 右侧**颜色清单**按数量列出已用色号，点击可在图中高亮对应像素（半透明覆盖层 + 亮度自适应描边，灰色等暗色也清晰可见）。
- **D 键（或右键）九宫格**（仅拖拽模式，先高亮像素）：优先取周围 8 格颜色，不足 9 个按相近度补齐，点击或按 **1-9** 快速改色。
- 画笔 / 取色 / 橡皮模式下按 **ESC** 返回拖拽。

### 4.5 工作区视图

- **侧边栏折叠 / 展开**：左侧「色板配置 & 编辑工具」与右侧「颜色清单」「事务历史」都可收起为窄条；颜色清单与事务历史点击标题栏即可收起/展开。左侧栏收起时画布保持屏幕原位，仅腾出更多工作区空间。
- **对比原图**：画布工具栏勾选后，工作区分为左右两块，左侧显示导入的原图（可独立拖拽缩放，不可编辑），右侧为拼豆图。
- **同步拖拽**：勾选后两侧使用一致的坐标与缩放（已按像素格放大与 5 格边距换算），在任意一侧拖拽 / 缩放，另一侧同步跟随；未勾选对比时勾选同步会自动开启对比，取消对比时同步一并取消。

### 5. 事务与撤销

- 工作状态自动保存，刷新后还原；「保存当前状态」或 **Ctrl+S** 保存一个独立快照（记录全部点位颜色，非树状结构）。
- 右侧「事务历史」以扁平列表展示所有状态，点击即可切换继续编辑，每个状态可单独删除；标题旁红字提示「有未保存的修改」。
- 工具栏提供**撤销 / 重做**（**Ctrl+Z / Ctrl+Y**，最多 20 步，增量记录）与自动保存信息；D 键改色、画笔 / 橡皮的整段拖拽各记一步。
- 重新压缩或调整颜色滑块会清空全部事务与撤销记录（有警告）；「清空所有状态」清空画布与全部历史。

### 6. 导出图片

- 导出 JPG / PNG，对话框左侧**实时预览**，右侧设置每格大小、网格线、外部白边、格内色号、色号图例、透明色与格式。
- 导出内容与画布效果一致（含 5 格透明边距与合并后的颜色效果），是否附带格内色号与图例由导出选项决定。

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 色板配置 | `data/configs/*.csv` |
| 当前状态与事务历史 | `data/state.json`（自动生成） |

> 「对比原图」使用的原图会缓存在浏览器 IndexedDB 中，刷新页面后对比功能仍可用；导入新图片时缓存会被新原图替换。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Ctrl+S / Cmd+S | 保存事务状态 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（最多 20 步） |
| D / 1-9 | 高亮像素的相近色九宫格 / 选择 |
| Esc | 关闭九宫格、返回拖拽模式 |
| 鼠标滚轮 / 拖拽 | 缩放 / 平移画布 |

> 网页内已拦截 Ctrl+S，不会触发浏览器「另存为」对话框。
