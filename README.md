# 拼豆工具

一套完整的拼豆（Perler / Fuse Beads）图案创建及辅助工具：导入图片 → 压缩成像素图 → 映射到豆色 → 简化颜色 → 手动编辑 → 事务历史 → 导出图片。

采用 **Python（Flask）后端 + HTML/JavaScript 前端**，数据保存在本地，下次打开自动还原。

## 运行方法

```bash
pip install -r requirements.txt
python app.py
```

然后打开浏览器访问 http://127.0.0.1:5000 即可。

> 需要 Python 3.9+，依赖 Flask、Pillow、NumPy。

## Docker / NAS 部署

1. 把项目放到 NAS 上（`git clone` 或直接上传）。
2. 编辑 `docker-compose.yml`：
   - `APP_TOKEN`：必填，改成你自己的访问 Token（页面登录用，不要使用示例值）；
   - `APP_SECRET`：可选，建议改成随机字符串（会话签名用）；
   - `PUID` / `PGID`：按 NAS 挂载目录的属主设置（默认 1000:1000）。
3. 启动：

```bash
docker compose up -d --build
```

4. 打开 `http://NAS地址:5000`，输入 Token 即可使用。

部署说明：

- 数据（色板配置、当前状态、事务历史）保存在 `./data` 目录，升级容器不会丢失。
- 容器启动脚本会自动保证 `data` 目录可写，并按 `PUID/PGID` 降权运行；首次启动若 `data/configs` 为空，会自动补齐内置的 48 色示例与 MARD 221 色配置。
- Token 验证：所有 API 都需要登录后才可访问，登录状态保存在会话 Cookie 中；页面上有“退出登录”按钮。
- 未设置 `APP_TOKEN` 时（本地开发）直接访问，无需登录。
- 生产模式使用 Waitress WSGI 服务（容器内默认开启）；公网访问请搭配 HTTPS 反向代理。

## 功能说明

### 1. 导入并压缩图片

- 支持常见图片格式，自动处理 EXIF 方向；PNG 等带透明通道的图片，透明区域导入后显示为空位（浅灰 X），半透明像素先按白底合成再取色。
- 采用「分块平均 + 感知色域量化」压缩，对二次元风格友好；可勾选**锐化**。
- **目标像素量**可单独设置（默认 40000），超出后自动按比例压缩；长条形图片也会等比缩放。
- 默认格子大小为 **26 像素**（导出默认值相同），格子内的色号标注清晰不重叠；单击「重新压缩」后图片会自动居中并适应窗口。
- 画布按像素格显示：格子间细线、每 5 格粗线、四周留 5 格空白，图案左上角始终对齐 5×5 网格。
- 可勾选**描边**，给图案外圈描一圈黑边。
- 四周 5 格空白以网格 + 灰色 × 显示（透明格，属于图片但不可改色），底色与橡皮清空后的空位完全一致；图片外侧再留出纯白边距。
- 可开启**显示色号**：在每个像素格内标注该豆的色号（导出时默认也带色号）。
- 图片正下方自动生成**色号图例**：每种已用颜色的色块、色号和数量，按豆数量从多到少排序，随编辑即时更新。

### 2. 豆色配置

- 默认使用 **MARD 221 色**配置（`data/configs/mard-221-alfonse-doudou.csv`，来自 [pindou-color-data](https://github.com/HansBug/pindou-color-data)），另内置一套 48 色示例配置（`data/configs/default_48.csv`）作为备用。
- 支持**新建 / 重命名 / 删除**配置，颜色表可直接编辑：豆编号、豆色号、名称、颜色。
- 支持从 **CSV 文件导入**与**导出为 CSV**（带 UTF-8 BOM，Excel 可直接打开编辑）。
- 切换配置时，画布上已使用的颜色会自动替换为最相近的新配置颜色。

CSV 表头格式（也兼容英文表头 `id/code/name/hex` 等）：

```csv
编号,色号,名称,颜色
1,001,白色,#FFFFFF
2,002,浅灰,#C8C8C8
```

### 3. 颜色简化

- 自动为每个像素计算与所有豆色中**距离最近**的颜色（默认 Lab 感知距离，可切换 RGB）。
- 唯一最近色直接确定；多个最近色按「已使用豆数量最多 → 左-上-右-下顺序」的规则依次确定。
- 采用**双副本**模型：
  - **基副本**：滑块调整前的完整颜色数据。拖动滑块时，呈现始终基于基副本重新合并。
  - **工作副本**：滑块调整后的结果，编辑（画笔 / 橡皮 / 取色 / D 键选色）都直接修改工作副本，所见即所得。
  - 编辑后再次拖动滑块会弹出警告：丢弃滑块调整后的编辑，并**清除上次使用滑块之后创建的全部事务**；确认后从基副本重新合并。
- 滑块会把最相近的颜色簇合并为一种保留色（按像素数加权），压缩到目标数量以内；颜色列表与图片下方图例的数量会随工作副本即时更新。

### 4. 编辑模式

- 默认是**拖拽模式**：在工作区任意位置拖动图片平移、鼠标滚轮缩放、单击某个像素可**高亮**该像素。
- 左侧「编辑工具」的全部颜色以 **6 列网格**展示（色块 + 色号 + 数量），点选一种颜色即进入**画笔模式**，点击/拖拽连续涂色（涂色不会产生高亮）；按 **ESC** 返回拖拽模式。
- **取色**工具：点击某个像素即可取用该格的颜色作为画笔色，并**自动切换为画笔模式**；按 **ESC** 返回拖拽模式。
- 点击**橡皮**进入橡皮模式，拖拽擦除；擦除后的格子为**空位（无豆）**，显示为浅灰斜线，与白色区分。
- 切换到画笔、取色或橡皮模式时会自动取消像素高亮。
- 工作区右侧有**颜色清单**：列出当前使用的全部色号与数量（按数量正序排列，数量少的优先），点击某个色号会在图片中用**该颜色的反色框**高亮所有该色像素；再次点击或选择其它色号会取消/替换，切换到画笔 / 取色 / 橡皮模式时全部取消；列表过长时可滚动。
- 单击「重新压缩」会同时清除像素高亮与颜色高亮。
- **仅拖拽模式**下，高亮某个格子后按 **D**（或右键）弹出九宫格：优先取周围一圈 8 个格子的颜色（去重，并排除格子自身的颜色），不足 9 个时再按相近度补齐；弹窗显示在像素下方并隔一个像素格，每个色块都标注色号，已使用的色号还会显示当前数量，点击或按数字键 **1-9** 直接选择；画笔、橡皮、取色模式下不触发。弹窗打开后如果直接拖拽或滚轮缩放（未选色），会自动关闭。

### 5. 事务功能

- 当前工作状态**自动保存**到本地，刷新 / 重启后自动还原。
- 单击「保存状态」或按 **Ctrl+S / Cmd+S**，把当前画面保存为一个事务状态（全量快照）。
- 右侧「事务历史」以**树形**展示所有状态：点击任意状态即可切换并继续编辑（会产生分支）。
- 每个状态可**删除**（连同其后的所有状态，删除前有警告）或**压缩**（移除该状态，其子树挂到上一个状态，压缩前有警告）。
- 「清空当前状态」会清空画布与全部事务历史（有警告）。

> 网页内已拦截 Ctrl+S，不会弹出浏览器「另存为」对话框（仅当焦点在本页面时生效）。

### 6. 导出图片

- 导出为 **JPG**（也支持 PNG），可设置每格大小、是否显示网格线、外部白边、是否描边、是否显示格内色号、是否附带色号图例。
- 导出内容与画布所见一致（包含 5 格透明边距、合并后的颜色效果、格内色号与图例）。

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 色板配置 | `data/configs/*.csv` |
| 当前状态与事务历史 | `data/state.json`（自动生成） |

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Ctrl+S / Cmd+S | 保存事务状态 |
| D | 拖拽模式下弹出高亮像素的相近颜色九宫格 |
| 1-9 | 快速选择框内选择颜色 |
| Esc | 关闭快速选择框 / 退出画笔、橡皮、取色模式 |
| 鼠标滚轮 | 放大 / 缩小画布 |
| 鼠标拖拽 | 平移画布（拖拽模式下在工作区任意位置均可） |
