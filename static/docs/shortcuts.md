## 快捷键说明

### 工具切换

- `Q`：画笔
- `W`：取色
- `E`：橡皮
- `R`：裁剪
- `M`：魔棒

### 编辑与选区

- `Shift + 单击`：追加选区
- `Ctrl / Cmd + 单击`（选择模式）：反选当前像素格
- `Ctrl / Cmd + 拖拽`（选择模式）：批量反选鼠标经过的格子
- `Shift + 拖拽`（画笔 / 橡皮）：从起点画横平竖直的直线
- `D`：九宫格快速改色（单选格优先，否则悬停格）
- `1-9`：在九宫格弹出时选择颜色
- `Delete`：清除选中格为空位

### 保存与撤销

- `Ctrl+S`：保存快照
- `Ctrl+Shift+S`：保存项目（.ssfbp）
- `Ctrl+Z`：撤销
- `Ctrl+Shift+Z` / `Ctrl+Y`：重做

### 视图与画布

- `Esc`：关闭弹窗 / 清除选择 / 返回选择模式
- 滚轮：缩放画布
- 右键拖拽：平移画布
