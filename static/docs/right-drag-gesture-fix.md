# 右键在界面上只画线不拖拽

## 问题现象

在拼豆工具界面里，按住鼠标右键拖动时：

- 页面上出现一条手势轨迹线（画线），而不是平移画布；
- 画到一半页面可能直接**后退 / 前进 / 关闭当前页**；
- 画布无法用右键拖拽平移，编辑被打断。

## 问题原因

这是 **Edge 浏览器内置的「鼠标手势」功能**造成的。该功能默认开启：按住鼠标右键绘制特定图案（比如向右、向下、画 L 形等）会触发前进、后退、刷新、关闭标签页等操作。拼豆工具用"右键拖拽"来平移画布，两者正好冲突。

> Chrome 浏览器没有内置鼠标手势，不需要处理；如果装了手势扩展，请在该扩展的设置里把本网站加入排除列表。

## 问题修复方案

### 方案一：只在本工具页面关闭手势（推荐）

1. 打开 Edge，在地址栏输入 `edge://settings/mouseGesture` 后回车；
2. 找到「配置鼠标手势」，向下找到「**配置阻止列表**」；
3. 点击「添加」，输入 `http://127.0.0.1`（工具默认访问地址），保存；
4. 刷新工具页面，右键拖拽即可正常平移画布。

> 注意：`http://localhost` 经测试无效，请使用 `http://127.0.0.1`。

### 方案二：彻底关闭 Edge 鼠标手势（影响所有网站）

1. 打开 Edge 设置（地址栏输入 `edge://settings`）；
2. 搜索「手势」，找到「鼠标手势」；
3. 关闭「启用鼠标手势」开关。

### 如果修复后又失效（设置同步的影响）

Edge 的「设置同步」会把浏览器设置同步到云端，可能把本地添加的阻止列表还原。此时：

- 方法一：在 Edge 设置里搜索「同步」（`edge://settings/syncSetup`），临时关闭同步，再按方案一添加一次；
- 方法二：保持同步开启，在 Edge 设置中手动添加一次——手动添加属于 Edge 自身的设置变更，会同步到云端，之后通常保持稳定。

## 恢复说明

修复后，右键拖拽 = 平移画布；左键单击 / 拖拽 = 选择格子。若想改回手势，到 Edge 设置中删除阻止列表条目或重新打开「启用鼠标手势」即可。
