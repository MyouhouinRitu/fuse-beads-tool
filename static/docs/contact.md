### 反馈问题前请提供

> 尽量按下面模板填写，能大大加快定位速度。

- **版本号**：{{APP_VERSION}}（界面左上角「拼豆工具」右侧）
- **系统环境**：Windows / macOS / Linux、Docker 或 EXE 打包版
- **复现步骤**：发生了什么、怎样操作能重现
- **日志**：打包版在 `data/app.log`；本地直开可看启动窗口输出
- **导出文件**：如与导出相关，可附上导出的图片 / PDF / 项目文件（.ssfbp）
